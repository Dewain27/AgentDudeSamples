# Security & Compliance Services  (`security-compliance`)

_Find and fix risk before it finds you._

**Product line:** Managed Services & Security  
**Scope:** assessment and hardening of applications and infrastructure against security risk, with support for compliance frameworks such as SOC 2 and HIPAA.  
**Best fit for:** healthcare, financial services, government, manufacturing, retail, education.  
**Indicative pricing:** Fixed price per assessment, or retainer · $90,000–$350,000 · 4 months is the typical full-scope engagement.

## Capabilities to describe in the proposed solution

- Security assessment of applications and infrastructure
- Penetration testing and remediation guidance
- Secure architecture and code review
- Compliance readiness (SOC 2, HIPAA, and similar)
- Identity, access, and secrets hardening
- Security monitoring and incident-response planning
