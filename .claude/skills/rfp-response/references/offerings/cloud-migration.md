# Cloud Migration  (`cloud-migration`)

_Move to the cloud with a plan, not a leap of faith._

**Product line:** Cloud & Platform Engineering  
**Scope:** assessment, planning, and execution of a migration from on-premises or legacy hosting to a modern, cost-efficient cloud environment.  
**Best fit for:** financial services, healthcare, government, manufacturing, education, retail.  
**Indicative pricing:** Fixed price per phase, invoiced on milestones · $200,000–$700,000 · 8 months is the typical full-scope engagement.

## Capabilities to describe in the proposed solution

- Migration assessment and readiness roadmap
- Landing-zone and network design
- Infrastructure-as-code environment build
- Application migration and validation
- Cost optimization and right-sizing
- Cutover and rollback planning

## Requirements this offering answers

If the RFP asks for these, this offering is the right match.

- Move applications off on-premises or legacy hosting
- Design a secure, well-architected cloud landing zone
- Migrate with minimal downtime
- Optimize and forecast cloud cost
- Provide infrastructure-as-code for repeatability
- Plan cutover and rollback

## Integrations

Typical systems this connects to — name the buyer's actual systems when the RFP identifies them, and keep these as the fallback.

- existing on-prem systems during transition

**Compliance frameworks:** SOC 2, ISO/IEC 27001.

## Differentiators specific to this offering

- Well-architected landing zone from day one, not retrofitted
- Cost modeling so the cloud bill holds no surprises

## Success measures buyers care about

Mirror these back in the executive summary when the RFP states similar goals — it shows you read their objectives.

- applications migrated with minimal downtime
- a secure, repeatable landing zone in infrastructure-as-code
- cloud cost forecasted and optimized

## Approved positioning language

Use these as the backbone of sections 3 and 4. Adapt the wording to the buyer's own terms; keep the substance.

**Understanding of needs:** You are moving off aging on-premises or legacy hosting and need a migration that is secure, low-risk, and cost-predictable — not a leap of faith.

**Proposed solution:** We start with an assessment and readiness roadmap, design a well-architected landing zone, build it as infrastructure-as-code, and migrate applications in planned waves with validation, cost optimization, and rollback plans at each cutover.
