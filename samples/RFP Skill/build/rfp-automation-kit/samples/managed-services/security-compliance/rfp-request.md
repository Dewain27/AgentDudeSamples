## 1. Introduction

Riverside Health Partners (a regional network of outpatient clinics, based in Ohio)
is seeking proposals from qualified software firms to deliver **Security & Compliance Services**
— assessment and hardening of applications and infrastructure against security risk, with support for compliance frameworks such as SOC 2 and HIPAA.

This Request for Proposal (RFP) describes our needs, the requirements a solution
must meet, and the process for submitting a proposal.

## 2. Scope of work

The vendor will be responsible for the full delivery lifecycle, including
discovery, design, development and configuration, integration, quality
assurance, data migration where applicable, training and documentation, and
deployment with post-launch support.

The capabilities we expect the solution to provide include:

- Security assessment of applications and infrastructure
- Penetration testing and remediation guidance
- Secure architecture and code review
- Compliance readiness (SOC 2, HIPAA, and similar)
- Identity, access, and secrets hardening
- Security monitoring and incident-response planning

## 3. Requirements

At minimum, the solution must:

1. Assess applications and infrastructure for security risk
2. Perform penetration testing and remediation
3. Review architecture and code for vulnerabilities
4. Prepare for a compliance framework (e.g. SOC 2, HIPAA)
5. Harden identity, access, and secrets management
6. Establish security monitoring and incident response

## 4. Integration requirements

The solution must integrate with our existing systems, including:

- Integration with the application and cloud environment under review.
- Integration with the identity provider (SSO).
- Integration with security monitoring / SIEM tooling.

Vendors should describe their approach to each integration and any assumptions.

## 5. Security and compliance requirements

The solution must adhere to **SOC 2, ISO/IEC 27001, HIPAA-aligned practices**, and vendors must describe:

- How data is encrypted in transit and at rest.
- How access is controlled (authentication, single sign-on, and roles).
- Their approach to security testing and vulnerability management.
- How the solution meets the accessibility and compliance frameworks above.

## 6. Success measures

We will consider this engagement successful if it achieves:

- critical and high findings remediated
- compliance readiness demonstrably improved
- security monitoring and incident response in place

## 7. Proposal requirements

Proposals must include, in order: (1) a cover letter, (2) an executive summary,
(3) your understanding of our needs, (4) the proposed solution and technical
approach, (5) a project plan and timeline, (6) the project team and key
personnel, (7) relevant experience and at least three references, (8) itemized
pricing with assumptions, and (9) assumptions, exclusions, and risks.
